# 🤖 ИИ-ассистент для салона красоты

## 📋 Описание проекта
Разработка и внедрение интеллектуального виртуального администратора для сети студий маникюра. Ассистент автоматизирует первичную коммуникацию с клиентами, консультирует по услугам и ценам, а также осуществляет запись на процедуры с синхронизацией в календарь.

Проект направлен на повышение конверсии заявок в записи, снижение нагрузки на живых администраторов и обеспечение круглосуточного сервиса для клиентов.

---

## 🎯 Цели и задачи
1.  **Автоматизация рутины:** Обработка до 80% типовых запросов (цены, адреса, свободные окна) без участия человека.
2.  **Увеличение записей:** Круглосуточный прием заявок и мягкое ведение клиента к целевому действию (записи) через персонализированные офферы.
3.  **Единый стандарт качества:** Трансляция ценностей бренда и соблюдение скриптов общения в каждом диалоге.
4.  **Интеграция процессов:** Бесшовная передача данных о записи в операционный календарь студии.

---

## ⚙️ Функциональные возможности

### 1. Осмысленное ведение диалога (NLP)
*   **Контекстуальная память:** Ассистент помнит имя клиента, выбранные услуги и предпочтения в рамках одной сессии.
*   **Адаптивный тон:** Стиль общения меняется в зависимости от настроения клиента (лаконичный для срочных записей, развернутый и вдохновляющий для сомневающихся).
*   **Сценарное поведение:** Строгое следование алгоритму: `Приветствие → Выявление потребности → Подбор времени/локации → Презентация выгоды → Запись`.
*   **Работа с возражениями:** Автоматические ответы на частые вопросы («дорого», «нет времени», «боюсь испортить ногти») с использованием аргументов из базы знаний.

### 2. Интеллектуальная база знаний
Ассистент отвечает строго на основе актуальных данных студии:
*   **Услуги и прайс:** Маникюр, педикюр, наращивание, дизайн (френч, стемпинг, «кошачий глаз»), мужской маникюр, уход (парафин, японский маникюр).
*   **Локации:** 4 адреса в г. Нижний Новгород (ТРЦ «Счастье», ТРЦ «Гагарина», ТРЦ «Жар-Птица», ул. Родионова).
*   **Акции и промокоды:** Автоматическое предложение промокода **ВПЕРВЫЕ** (маникюр + гель-лак за 1990 ₽ вместо 2590 ₽) для новых клиентов.
*   **Экспертность:** Упоминание основателя и стандартов стерилизации.

### 3. Запись и синхронизация (Google Calendar)
*   **Сбор данных:** Пошаговый сбор имени, контакта, желаемой услуги, даты, времени и предпочтительной студии.
*   **Создание события:** Автоматическое добавление встречи в **Google Calendar** с подробным описанием:
    *   Название: «Маникюр — [Имя Клиента]»
    *   Время и дата.
    *   Локация (адрес студии).
    *   Комментарий: выбранные опции (дизайн, покрытие), контакт клиента, источник (ИИ-ассистент).
*   **Напоминания:** Генерация текста для последующей отправки напоминаний клиенту.

## 🛠 Технологический стек

| Компонент | Инструмент / Сервис | Роль в проекте |
| :--- | :--- | :--- |
| **Интеллект и Логика** | **Qwen** | Создание системного промпта, формирование структуры базы знаний, настройка логики ответов и стиля общения (tone of voice). |
| **Платформа ассистента** | **Savvy** ([suvvy.ai](https://suvvy.ai/)) | Хостинг бота, интерфейс диалога, подключение внешних инструментов (Google Calendar API), управление сценариями. |
| **Календарь** | **Google Calendar** | Хранение расписания, синхронизация записей, визуализация занятости мастеров. |
| **База знаний** | **PDF / Текстовые данные** | Структурированная информация об услугах, ценах, адресах и правилах студии. |

## 📝 Пример сценария работы (User Flow)

1.  **Клиент:** «Здравствуйте, хочу сделать маникюр.»
2.  **ИИ-ассистент:** «Здравствуйте! 🌸 Я помощник студии. Подскажите, какой результат вы хотите получить? (Покрытие Luxio, наращивание, дизайн или уход?)»
3.  **Клиент:** «Нужно покрытие гель-лак с френчем, желательно завтра вечером.»
4.  **ИИ-ассистент:** «Отличный выбор! Френч у нас выполняется премиум-материалами. В какой студии вам удобнее?
    *   ТРЦ «Счастье» (ул. Горького, 70)
    *   ТРЦ «Гагаринский»
    *   ТРЦ «Жар-Птица»
    *   ул. Родионова, 189/24»
5.  **Клиент:** «Давайте на Горького.»
6.  **ИИ-ассистент:** «Прекрасно! На завтра вечер есть окна. Кстати, если вы у нас впервые, при онлайн-записи с промокодом **ВПЕРВЫЕ** цена составит **1990 ₽**. Назовите ваше имя для записи?»
7.  **Клиент:** «Анна, +7900...**»
8.  **ИИ-ассистент:** «Готово, Анна! ✨ Вы записаны на завтра в 19:00 в студию на ул. Горького. Встреча добавлена в календарь. Ждем вас!»
    *(В этот момент событие создается в Google Calendar)*.

## 🚀 Результаты внедрения
*   **Скорость реакции:** Мгновенный ответ клиенту 24/7.
*   **Конверсия:** Рост записей за счет оперативной обработки лидов и использования триггерных акций.
*   **Экономия времени:** Администраторы освобождаются от рутинных переписок и фокусируются на сервисе в зале и сложных запросах.
*   **Порядок в расписании:** Исключение человеческой ошибки при переносе данных из чата в календарь.
